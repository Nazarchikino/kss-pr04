# rest-api-design – стартовий проєкт до практичної роботи № 4

Освітній компонент «Розробка клієнт-серверних застосувань», розділ 2.
Тема: проєктування REST API інформаційної системи: ресурси, маршрути, коди станів, версіонування.

```
npm install
npm run lint     # перевірка специфікації правилами стилю курсу (Spectral)
npm run docs     # документація → docs/index.html (Redocly)
npm run mock     # імітаційний сервер http://localhost:4010 за специфікацією (Prism)
```

| Файл | Що робити |
|---|---|
| `VARIANTS.md` | знайдіть свій варіант |
| `DESIGN.md` | частина 1: ресурси, таблиця маршрутів, проєктні рішення |
| `openapi.yaml` | частина 2: специфікація OpenAPI 3.1 (шаблон з готовими компонентами) |
| `.spectral.yaml`, `functions/` | правила стилю курсу – **не змінювати** |

Потрібен Node.js 24 LTS або новіший.
